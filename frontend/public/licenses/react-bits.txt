SpotlightLink is adapted from React Bits SpotlightCard (TypeScript + CSS).
Source: https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components/SpotlightCard
Retrieved: 2026-09-22. Adaptations: semantic router link, motion opt-out, pointer filtering, local theme.

Shared visual effects (retrieved 2026-09-22):
DarkVeil shader: https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Backgrounds/DarkVeil
CountUp / GradientText: https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/TextAnimations
MagicBento / AnimatedList / GooeyNav / StarBorder / ElectricBorder:
https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components
ClickSpark: https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Animations/ClickSpark
Adaptations: DarkVeil shader retained, bounded FPS/DPR and resource lifecycle added;
Motion-based counting/entry/selection, finite GSAP particles, CSS gradient/border
and canvas spark/electric visual algorithms adapted to native application controls.
These are scoped adaptations, not unmodified copies or complete upstream APIs.
No sample catalogs or business events used.

Original vertex/fragment shader algorithms retained verbatim in effects/backgrounds.
AmbientField supplies shared OGL lifecycle, per-route palette/parameters, lazy shader
imports, 30 FPS/DPR 1.5/internal resolution cap, visibility suspension and GPU disposal.
Aurora/RippleGrid use upstream light mode; the other shaders use CSS opacity over the
light canvas. Lightweight/off modes use a static route palette, without WebGL.
The previous application-drawn line motifs have been replaced, not rebranded.
Stack: https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components/Stack
ChromaGrid: https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components/ChromaGrid
Adaptations: stacked-card composition with finite CSS entry and explicit accessible
next/previous controls (no autoplay, drag-only controls or upstream example data);
per-card low-saturation accents and pointer spotlight use real catalog metadata.
DarkVeil uses the upstream light-mode shader with low opacity. The application
retains its original native controls and business logic.
