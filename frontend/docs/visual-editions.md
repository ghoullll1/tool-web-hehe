# 双版本视觉：经典版 / Light Studio 现代版

## 方向与兼容

当前新版采用浅色工作室，不再使用此前的整页紫色科技主题。白色工作表面、浅灰背景，以及低饱和蓝、靛、玫瑰、琥珀、石板色作为局部标识。经典版的颜色、布局和业务行为保留。

首次升级默认进入现代版；浏览器 `tool-web.appearance.v2` 保存 `edition` 和 `motion`。旧版 v1 明确关闭动效时迁移为关闭，此后始终尊重 v2 选择。已有 v2 用户保持原选择，不再次强制切换。存储不可用时仍可正常操作。

切换只更新共享外观状态，不替换工具组件、输入、文件、转换结果或 WebSocket。工具目录始终来自后端，`studioProfiles.ts` 仅指定视觉属性，不生成目录或过滤业务工具。

## 页面与交互

- 首页：双栏编辑式布局；左侧搜索和真实统计，右侧可翻阅的工具卡片栈；完整目录有独立分类栏及卡片/列表视图。
- 导航：固定工作区标题、真实分类数量、名称筛选、分组折叠和滑动选中底板。手机为支持 Escape、焦点约束、返回焦点的抽屉。
- 工具页：面包屑与“专注工作”仅控制介绍区显示，不卸载工具。不同工具使用不同的工作空间。
- 配置转换：桌面参数侧栏、双栏编辑器、折叠规则；窄屏顺序堆叠。自动识别、转换、大小限制、重复键策略均保持原逻辑。
- 图片转换：棋盘画布与输出参数侧栏，玫瑰色强调。
- 文档转换：紧凑投入口与更宽的纸张预览，琥珀色强调。
- 会话：双人邀请卡片布局；进入会话后完整聊天台。称呼与原会话生命周期不变。
- 网络诊断：紧凑配置台与模块化结果；时间、密码、分享工具保留专业控件并分别使用对应色调。

## React Bits 适配

| 区域 | 来源 | 实现边界 |
| --- | --- | --- |
| 首页背景 | DarkVeil | 官方 light-mode 着色器 + OGL；低透明度、静态回退，不穿过编辑文字 |
| 工具页留白 | Aurora / Threads / Iridescence / LiquidChrome / Balatro / RippleGrid | 直接采用官方 GLSL 算法，按工具配置配色、速度、尺度；独立懒加载、统一 OGL 生命周期，编辑面板保持不透明 |
| 首页卡片栈 | Stack | 卡片叠层与有限入场，原生上一项/下一项按钮；真实 API 工具，不自动翻页 |
| 标题/统计 | GradientText / CountUp | 缓慢低饱和渐变与首次数字递增，读屏获得最终真实值 |
| 快捷工具 | MagicBento | GSAP 轻微倾斜、有限粒子、局部聚光 |
| 完整目录 | SpotlightCard / ChromaGrid | 每张卡片按工具视觉配置使用不同局部色，指针光晕不移动文字 |
| 导航 | AnimatedList | 分组入场、展开过渡、路由底板移动 |
| 分类/格式 | GooeyNav 视觉语言 | Motion 受控选中底板，不改原语义和键盘行为 |
| 操作 | StarBorder / ClickSpark | 悬浮边缘流光、点击后短时且随工具色的火花 |
| 上传/处理 | ElectricBorder | 只在拖入或实际忙碌状态绘制边框 |

这些是保留上游视觉算法或视觉语言的按需适配，并非完整移植全部上游组件 API。来源与 MIT + Commons Clause 许可随站点发布在 `public/licenses/react-bits.txt`，不能视为无附加限制的 MIT。参考：https://reactbits.dev/ 。

## 文件职责

- `src/appearance/AppearanceProvider.tsx`：v2 偏好迁移、实际动效等级、html 属性。
- `AppearanceSwitch.tsx`：现代版（左侧默认项）/经典版、完整/轻量/关闭开关。
- `StudioStack.tsx`：真实目录推荐卡片；`StudioToolbar.tsx`：专注布局控制。
- `studioProfiles.ts`：19 个已注册工具的展示风格与未知工具安全回退。
- `modern.css`：浅色 token 与语义兼容；`nebula.css`：首页、导航和反馈层（保留原文件名）。
- `studioWorkspaces.css`：按任务类型设计的工具布局。
- `AmbientBackdrop.tsx` / `ambient.css`：工具页背景容器、浅色适配和截图问题修正；`effects/AmbientField.tsx`：统一官方着色器生命周期，30 FPS、DPR 1.5、渲染长边 1600 像素上限。轻量/关闭保留静态渐变，经典版不挂载。
- `ambientMotifs.ts`：19 个工具的独立背景参数，分配六种上游效果，而非 19 个自绘图案；映射不参与工具目录生成。`effects/backgrounds/` 保留官方 GLSL 与原始来源，`uniforms.ts` 对接官方参数。
- `palette/`：15 份 scoped 样式桥接，覆盖现有 19 个工具，经典版不生效。
- `effects/`：可视区暂停、选择底板、有限粒子与 canvas / WebGL 生命周期。
- `useNavigationDrawer.ts`：手机抽屉键盘、inert 与焦点恢复。

## 性能和验证

动效支持完整、轻量、关闭。系统减少动态效果优先关闭；手机/粗指针将完整降为轻量。同屏最多一个 WebGL 背景，DPR 上限 1.5、30 FPS；离屏/后台暂停，经典/关闭/轻量卸载 WebGL。故障回退静态背景。点击粒子没有空闲 RAF，所有装饰不接收指针、不进入读屏顺序。

运行 `npm test`、`npm run lint`、`npm run build`、`npm run ui:check`。修改原业务 CSS 后运行 `npm run ui:palette`；专用布局写入手工视觉层。自动测试包含迁移、异常存储、降级、输入/文件/会话保留、使用统计不重复、资源释放、真实卡片栈及目录视图。

浏览器检查使用真实 8090 目录，不向外发送诊断请求、不上传真实文件、不创建服务器会话。布局验收不等于全部外部服务端到端验收；业务行为由原测试及新增兼容测试保障。

截图回归重点：主按钮及下拉选中标记的前景/背景对比度；切换组的边框、静态选中态和 Motion 底板；端口频谱与数字徽标留白；配置页以命名网格区域保持完整/专注模式对齐。装饰关闭时仍保留所有选中标记。工具操作的点击反馈仅在完整动效下短时运行，输入与结果不位移。

嵌套切换组的动画只挂在按钮共同父元素，标签不进入底板范围，装饰始终位于文本下方。JSON 差异新增/删除/修改使用独立绿/红/黄语义色，不受工具主题色替换。
